# Network Monitoring Mini Project

## Why I Built This Project

As a fresher preparing for monitoring and infrastructure roles, I wanted to understand how servers are checked in real-time. Instead of only studying theory like "incident" and "SLA", I tried to build a small simulation project to understand how monitoring actually works.

## What This Project Does

- Checks if a server is reachable using ping.
- Prints whether the server is UP or DOWN.
- If the server is down, it logs the issue with date and time.
- If the issue continues, it increases the severity level.
- Calculates uptime percentage based on successful checks.

## What I Learned

Through this project, I understood:

- How ping works using ICMP.
- How monitoring systems detect failures.
- How incidents are logged.
- How escalation works when an issue is not resolved.
- How uptime percentage is calculated.

This is a simple simulation project created to strengthen my understanding of monitoring concepts.
